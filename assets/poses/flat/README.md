# Toto · Flat stickers

[Español](README.es.md) · [Main collection](../../../README.md)

Ten alternative 2D sticker-style poses of Toto, the European red fox and official mascot of Spanish Total.js. Flat colours, clean charcoal contours and transparent backgrounds.
